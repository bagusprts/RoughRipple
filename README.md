# RoughRipple

RoughRipple optimizes real-time data processing through distributed streaming ingestion, utilizing processor and pipeline architectures.

RoughRipple is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughRipple.git`
2. `cd RoughRipple`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
